# Smart Conveyor Digital Twin

Digital Twin-Based Prognostics for Smart Conveyor.

## Phase 1
Clean, light-theme engineering dashboard using demo sensor data.

## Planned integration
- ESP32 sensor acquisition
- MQTT communication
- Maxbyte Digital Twin
- Anomaly detection
- AI-based prognostics
- Maintenance recommendations

## Dashboard parameters
- Temperature
- Vibration
- Motor current
- Voltage
- Speed
- System health
- Sensor trends
- Condition/prognostics
- Maintenance actions
- Alerts

## Run locally

```bash
npm install
npm run dev
```
